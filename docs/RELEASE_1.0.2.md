# Boundary 1.0.2

Adds a dark reference-based navigation shell, match search, player career profiles
and local rankings, tournament batting/bowling/fielding/all-round leaderboards,
NRR scenario planning, Manhattan and worm graphs, transparent match awards,
device-local squad availability, and RTMP/RTMPS camera publishing.

The web release includes an OBS scoreboard overlay and Clerk-authenticated
community posts/replies backed by Neon. Shop, merchandise, advertising and
subscription gates are excluded.

This is an incremental release, not full CricHeroes parity. Clerk remains in
development mode; first-user posting, native device acceptance and streaming to
a real ingest endpoint are unverified. Shared match authority, private messaging,
automated video highlights and broader Pro functionality remain incomplete.

The Android release uses the existing signing key for upgrade continuity.
