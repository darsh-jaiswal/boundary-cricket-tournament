# Boundary Android 1.0.12

Google sign-in prompts now use Google's unmodified pre-approved light pill button
with its full-colour G logo and Sign in with Google label. The website uses the same
artwork for its existing Clerk Google sign-in action. Android welcome, account,
profile, statistics and team-entry prompts share the button with an accessible label
and a minimum 48dp touch target. Account management remains available when signed in.

This release changes button presentation only. Registration, device approval,
guest entry and username rules keep their existing behaviour.
