# Boundary Android 1.0.6

Includes the latest home, profile, match detail, player follows and QR scanning, store, and My Performance screens. Player names on match screens open their statistics. Corrects runs and wagon-wheel zones for a batter run out at the non-striker's end.

This release retains the existing signing certificate and increments Android versionCode to 7, allowing an update over the signed 1.0.5 installation.

Match scoring remains local-first. Registration, community, connections, shop and match publication require connectivity. The shop stays in preview until inventory and fulfilment are configured.

Validation: signed release build, debug unit tests, APK signature and version checks, and deployed download checksum verification. Physical-phone testing is left to the user; no device was connected during release preparation.
