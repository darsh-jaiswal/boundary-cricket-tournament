# Boundary 1.0.4

The scorer now supports wicket and extras entry with dismissal legality checks, dismissal and fielder corrections in the delivery journal, mid-over bowler replacement, and enforcement of bowler over limits and consecutive-over restrictions. Undo and event reversal recalculate the innings from the saved journal. Match rules lock after the first scored delivery.

Match setup includes quick presets for T20, T10, Hundred-style five-ball overs, four-ball box cricket, and eight-ball cricket, while retaining custom rules. A tied match can start a one-over Super Over with two wickets per side, then continue into additional Super Overs if still tied. Super Over innings appear in scorecards and public match pages; tournament standings and career leaderboards continue to use the regulation innings, with net run rate based on the main match.

The signed Android release is version 1.0.4. Release assembly and Android release lint completed. Physical-device match scoring, voice recognition accuracy, and full workflow parity with CricHeroes have not been independently checked.
